# Ink & Linen Studio

A fictional painting and drawing studio site for Mara Ellison. Visitors ask about a named work, a commission, or a workshop date on WhatsApp. There is no cart and no price list.

Demo: https://mohammedbagowabair.github.io/Ink-and-Linen-Drawing-Studio-Website/

Plain HTML, CSS, and JavaScript. Photographs are from Pexels and credited in the footer. The artist is not a real person.
